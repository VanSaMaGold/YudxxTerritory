# YudxxTerritory

A Minecraft territory (plot) management plugin for Spigot/Paper servers.

## Commands

- `/territory auto` - Auto-claim a territory
- `/territory claim` - Claim the territory you are standing on
- `/territory home [index]` - Teleport to your territory
- `/territory visit <player>` - Visit another player's territory
- `/territory gui` - Open territory main menu
- `/territory settings` - Open territory settings menu
- `/territory trust <player>` - Trust a player on your territory
- `/territory untrust <player>` - Remove trust from a player
- `/territory ban <player>` - Ban a player from your territory
- `/territory unban <player>` - Unban a player from your territory
- `/territory merge` - Merge with adjacent territory
- `/territory unmerge` - Cancel all merges
- `/territory setname <name>` - Set a name for your territory
- `/territory info` - View current territory info
- `/territory list` - View your territory list
- `/territory middle` - Teleport to territory center
- `/territory kick <player>` - Kick a player from your territory
- `/territory clear` - Clear your territory blocks
- `/territory undo` - Undo the last clear operation
- `/territory delete` - Delete your territory
- `/territory help` - Show command help

## Admin Commands

- `/territoryadmin createworld <world>` - Create a territory world
- `/territoryadmin generateworld <world>` - Generate territory world terrain
- `/territoryadmin deleteworld <world>` - Unload a territory world
- `/territoryadmin setborder <world> <material>` - Set border material
- `/territoryadmin info <world> <x> <z>` - View territory admin info
- `/territoryadmin delete <world> <x> <z>` - Force delete a territory
- `/territoryadmin clear <world> <x> <z>` - Force clear a territory
- `/territoryadmin reset <world> <x> <z>` - Reset a territory
- `/territoryadmin permissions` - View all permission nodes
- `/territoryadmin reload` - Reload configuration
